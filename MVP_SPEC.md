# MVP-спецификация: антигравити — шагомер с атмосферой

## 1) Цели MVP
- Мотивировать ходить через прогресс по миру и награды за достижение локаций.
- Показать, что шаги → расстояние → локации (на карте) работает с реальными данными.
- Дать базовую геймификацию: лор‑квиз и внутриигровые очки.

## 2) Основные пользовательские истории
1. **Как пользователь**, я хочу выбрать вселенную и увидеть маршрут, чтобы понимать, куда иду.
2. **Как пользователь**, я хочу подключить Apple Health / Google Fit, чтобы шаги считались автоматически.
3. **Как пользователь**, я хочу видеть дневной прогресс (шаги, км, калории), чтобы отслеживать результат.
4. **Как пользователь**, я хочу получать награды за достижения локаций, чтобы было интересно идти дальше.
5. **Как пользователь**, я хочу отвечать на вопросы по лору, чтобы получать дополнительные очки.
6. **Как пользователь**, я хочу тратить очки на скины, чтобы персонализировать опыт.

## 3) Экранная карта (MVP)
1. **Онбординг**
   - Цель: объяснить механику «шаги → локации → награды».
2. **Выбор вселенной**
   - Средиземье / WoW / Ведьмак.
3. **Подключение здоровья**
   - Разрешения HealthKit / Google Fit.
4. **Главный экран (Дневник)**
   - Прогресс дня, текущая локация, кнопка «Синхронизировать».
5. **Карта мира**
   - Маршрут, ключевые точки, пройденное расстояние.
6. **Экран локации**
   - Описание места, награда, вопрос по лору.
7. **Экран награды**
   - Очки, статус прогресса.
8. **Магазин**
   - Каталог скинов, покупка за очки.
9. **Профиль**
   - Статистика по дням/месяцам, накопленные очки.

## 4) Функциональные требования
### 4.1 Синхронизация шагов
- Ежедневная синхронизация с HealthKit/Google Fit.
- Показ шагов, расстояния, калорий, времени активности.

### 4.2 Карта и расстояния
- Реальные координаты локаций.
- Прогресс рассчитывается в км по маршруту.

### 4.3 Лор‑квизы
- 1 вопрос при достижении локации.
- Правильный ответ → +очки.

### 4.4 Награды
- Очки за достижение локаций.
- Дополнительные очки за квизы.

### 4.5 Магазин
- 5–10 скинов в MVP.
- Покупка за внутриигровые очки.

## 5) Нефункциональные требования
- Приложение должно работать оффлайн (последняя синхронизация + кеш картинок).
- Данные пользователя синхронизируются между устройствами.
- Уведомления о достигнутых локациях (по желанию).

## 6) Приоритеты MVP
### Must‑have
- Подключение HealthKit/Google Fit.
- Дневной прогресс.
- Маршрут + ключевые локации.
- Награды и очки.

### Should‑have
- Лор‑квизы.
- Генерация изображений.

### Nice‑to‑have
- Социальные функции.
- Лидерборды.
